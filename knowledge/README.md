# 직원 참고서 (knowledge)

직원(에이전트)이 일하기 전에 읽는 업무 참고서입니다. AI 직원은 대화가 끝나면 배운 것을 잊기 때문에, 계속 지켜야 할 지식은 여기에 파일로 둡니다.

| 파일 | 읽는 직원 | 내용 |
|---|---|---|
| `노동법-5인미만.md` | 병원 인사 (`hospital-hr`) | 5인 미만 적용·미적용 조항, 최저임금, 주휴·퇴직금·해고예고 계산 |
| `캠프나인-근로계약서-정규직.md` | 병원 인사 (`hospital-hr`) | 현재 쓰는 정규직(주 35시간) 근로계약서(개인정보 삭제본)와 고칠 점 — **새 계약서의 기본 양식** |
| `캠프나인-근로계약서-일용직.md` | 병원 인사 (`hospital-hr`) | 현재 쓰는 일용직 근로계약서(개인정보 삭제본)와 고칠 점 |
| `의료광고-의료법.md` | 병원 홍보 (`hospital-marketing`), 병원 사무 (`hospital-office`) | 의료법 56조 금지 유형과 치과 예시, 환자 유인 금지, 사전심의, 게시 전 체크리스트 |

## 업무 양식 (`templates/`)

| 파일 | 쓰는 직원 | 내용 |
|---|---|---|
| `templates/근로계약서-정규직.md` | 병원 인사 | 정규직 근로계약서 개정 양식 (토요일 휴게 12:00~13:00 반영, 세전 기준, 휴가 방침 선택란) |
| `templates/근로계약서-일용직.md` | 병원 인사 | 일용직 근로계약서 개정 양식 |

## 계산 도구 (`tools/`)

| 파일 | 쓰는 직원 | 내용 |
|---|---|---|
| `tools/세후역산.py` | 병원 인사 | 협상한 세후 월 수령액 → 계약서용 세전 기본급 역산, 공제 내역·최저임금 확인 (2026·2027 요율) |

- 요율은 매년 바뀐다. **매년 1월**에 국민연금·건강·장기요양·고용보험 요율과 최저임금을 확인해 `tools/세후역산.py` 맨 위 표를 고친다. 2027년 국민연금 5%(근로자)는 개혁 일정 기준값이므로 공단 고시로 확인한다.

## 관리 원칙

- 각 파일 맨 위의 **작성일·다음 점검일**을 지킨다. 점검일이 지났으면 직원은 답하기 전에 최신 정보를 검색해 확인하고, 바뀐 내용을 비서실장에게 보고한다.
- 원장님이 주신 자료(심의 반려 문구, 노무사 조언, 계약서 양식 등)는 해당 파일의 **"캠프나인 사례"** 항목으로 추가한다. 환자·직원 실명과 금액 원본은 넣지 않는다.
- `tests/` 폴더는 직원 실력 점검용 시험지와 답안이다. **직원은 업무 중에 `tests/` 폴더를 열지 않는다.**
