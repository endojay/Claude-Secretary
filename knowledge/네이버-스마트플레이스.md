# 네이버 스마트플레이스 참고서 — 캠프나인치과

> **작성일: 2026-11-21** · 다음 점검: 2027-05 또는 네이버 공지 변경 시
> **확인 수준**: 아래 1번은 원장님이 주신 네이버 스마트플레이스 공지 캡처(2026.11.13 게시, 공지번호 1162, "[병의원] 우리 병의원이 더 많은 검색어에 노출됩니다") 내용을 정리한 것. 공지에 없는 내용은 "추측"으로 표시했다. 치과 카테고리 이름과 세부 버튼 이름은 캡처에 없어 확인되지 않았다.

## 1. 공지 요약: 병의원 검색 확대 (2026.11.12 시행)

- **시행일**: 2026-11-12(목)부터 네이버 플레이스 병의원 검색 확대. 진료과목뿐 아니라 **증상·질병·시술·검진명**으로 검색해도 병원이 노출된다.
- **노출 기준**: 10월 29일 안내된 **「우리병원 검색 키워드」**에 등록한 키워드로 실제 노출이 시작됐다. 미등록 병원은 지금 등록하라고 권장.
- **이용자 검색 방식**: 평소 말로 검색. 증상만, 또는 지역·진료과·진료시간을 붙여서 (예: "강남 이석증 병원", "야간 두드러기 병원").
- **분류 4가지**: 증상 / 질병 / 시술 / 검진. 통합검색·플레이스·지도앱·PC지도에 '진료 분야 필터'(증상·질병·시술·검진)가 새로 생겼고, 키워드가 정확히 등록될수록 잘 매칭된다.
- **등록 위치**: 스마트플레이스 [업체정보 > 제공 서비스 > 우리병원 검색 키워드]. **4개 분류 합쳐 최대 30개.**
- **등록 방식**: 검색창("검색어를 입력해 주세요")에서 검색하거나 카테고리 카드에서 고르는 화면. 자유 입력이 아니라 **네이버가 가진 목록에서 선택하는 방식으로 보인다** (캡처 해석, 확정 아님).
- **유의 사항**
  - 반영까지 시간이 걸린다.
  - 심평원 진료정보 기반 '다빈도 진료 질병'이 상세페이지에 자동 노출된다.
  - 광고가 아닌 일반 검색 영역이며, 키워드를 많이 넣는다고 상위 노출이 보장되지 않는다.

## 2. 캠프나인 운영 원칙 (홍팀장 판단, 공지에 없는 부분)

- **지역명("동탄")은 키워드로 넣지 않는다.** 공지상 지역은 이용자가 검색어에 붙이는 조건이고, 키워드 항목은 증상·질병·시술·검진이다. 위치는 등록된 병원 주소로 매칭될 것으로 **추측**된다 (공지에 명시 없음).
- **실제 하는 진료만 등록한다.** 하지 않는 진료를 넣으면 제56조 제2항 3호(거짓 광고) 소지. 확인되지 않은 항목은 원장님 확인 후 등록. (2026-11-21 원장님 확인: 임플란트·사랑니·발치·턱 통증 시행, 구취 치료는 하지 않음, 교정은 미확인이라 제외, 금연프로그램 운영)
- **금지 표현**: 목록 선택 방식이라 대부분 해당 없지만, 직접 입력칸이 있거나 소개글에 옮길 때는 "무통", "최고", "전문", "명의" 등 쓰지 않는다 (참고서 `의료광고-의료법.md` 2번).
- **캠프나인의 진료 강점으로 확인된 분야**: 신경치료, 잇몸치료, 임플란트 (예약업무 지침 기준, 시행 범위 세부는 원장님 확인). 진료 철학은 자연 치아 살리기.
- 키워드는 분기마다 한 번 점검하고, 진료 항목이 바뀌면 같이 고친다.

## 3. 캠프나인 등록 키워드 (2026-11-21 원장님 직접 저장, 30/30)

원장님이 실제 화면에서 저장한 목록. 아래 사실은 저장 화면 캡처로 확인했다.
- 화면 구성: 진료과목(심평원 등재 과목 자동 반영, 캠프나인은 '치과') → 우리병원 검색 키워드(검색창 + 분류 카드) → **검색 제외 키워드**(최대 30개, 이 단어로 검색하면 우리 병원이 노출되지 않음).
- 분류 카드 숫자 = 선택한 수 / 치과에서 선택할 수 있는 항목 수: 증상 2/7, 질병 8/21, 시술 19/43, 검진 1/1. 즉 치과 선택지는 모두 72개, 자유 입력은 안 되고 목록에서 고른다.

**저장된 30개** (화면 순서): 치통, 신경치료, 충치, 라미네이트, 레진충전, 치아변색, 치아브릿지, 치아미백, 치석, 잇몸치료, 임플란트, 턱관절, 턱관절장애, 발치, 이갈이, 크라운, 사랑니발치, 매복사랑니, 시린이, 잇몸병, 보철, 부분틀니, 불소도포, 스케일링, 심미보철, 인레이, 잇몸관리, 잇몸성형, 틀니, 구강검진

- 금연프로그램은 목록에 없어 빠진 것으로 보인다 (원장님 확인 필요).
- 비슷한 항목이 겹친다(턱관절/턱관절장애, 잇몸치료/잇몸관리/잇몸병, 사랑니발치/매복사랑니, 보철/심미보철). 칸을 바꾸고 싶을 때 먼저 정리할 후보.
- 검색 제외 키워드는 0개. 하지 않는 진료(예: 치아교정)를 넣는 것은 선택 사항이다.
- 다음 점검: 분기 1회, 진료 항목이 바뀔 때.
