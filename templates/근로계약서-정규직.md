# 근 로 계 약 서

**캠프나인치과의원**(이하 "갑")과 근로자 **【근로자 성명】**(이하 "을")은 다음과 같이 근로계약을 체결하고 성실히 이행할 것을 약정한다.

## 1. 계약 당사자

| 구분 | 항목 | 내용 |
|---|---|---|
| (갑) 사용자 | 상호 | 캠프나인치과의원 |
| | 대표자 | 【대표자 성명】 |
| | 주소 | 경기도 화성시 동탄순환대로 127-5, 613·614호 |
| (을) 근로자 | 성명 | 【근로자 성명】 |
| | 생년월일 | 【생년월일】 |
| | 주소 | 【근로자 주소】 |
| | 연락처 | 【근로자 연락처】 |

> 주민등록번호는 4대보험 신고에만 필요하므로 계약서에는 생년월일만 적는다.

## 2. 근로계약 기간
- 근로개시일: 【____년 __월 __일】
- 근로계약 기간: **기간의 정함 없음**
- 수습기간: 근로개시일부터 【1개월】

## 3. 근무 장소 및 업무
- 근무 장소: 캠프나인치과의원 (사용자의 사업 소재지)
- 종사 업무: 【치과위생사 / 치과조무사 / 데스크 등】 및 이에 부수하는 업무

## 4. 근무일 및 근로시간

| 요일 | 근무시간 | 휴게시간 | 실근로시간 |
|---|---|---|---|
| 월요일 | 10:00 ~ 19:00 | 12:30 ~ 14:00 | 7.5시간 |
| 화요일 | 10:00 ~ 19:00 | 12:30 ~ 14:00 | 7.5시간 |
| 수요일 | 10:00 ~ 19:00 | 12:30 ~ 14:00 | 7.5시간 |
| 목요일 | 휴무 | — | 0시간 |
| 금요일 | 10:00 ~ 19:00 | 12:30 ~ 14:00 | 7.5시간 |
| 토요일 | 10:00 ~ 15:00 | 12:00 ~ 13:00 | 4시간 |
| 일요일 | 주휴일 | — | — |
| **합계** | | | **주 34시간** |

1. "갑"은 업무상 필요한 경우 "을"의 동의를 얻어 1주 12시간 범위에서 연장근로를 명할 수 있다.
2. "갑"은 업무상 필요한 경우 "을"의 동의를 얻어 휴일근로 및 야간근로를 명할 수 있다.
3. 휴게시간은 진료 질서를 해치지 않는 범위에서 자유롭게 이용할 수 있다.
4. 위 1~2항의 연장·휴일·야간근로에 동의함: 근로자 ______________ (서명 또는 인)

## 5. 임금

1. 임금은 **세전 금액**으로 정하며, 매월 다음과 같이 지급한다.

| 항목 | 금액(월, 세전) | 시간 | 계산 방법 |
|---|---|---|---|
| 기본급 | 【______】원 | 177.3시간 | 통상시급 × 월 소정근로시간 (주휴수당 포함) |
| 연장근로수당 | 발생 시 | 실제 시간 | 통상시급 × 월 연장근로시간 (1배) |
| 식대 | 【______】원 | — | 비과세 (월 20만 원 한도) |
| **월 급여 총액** | **【______】원** | | |

   - 통상시급: 【______】원 (= 기본급 ÷ 177.3시간)
   - (참고) 협의한 세후 월 수령액: 【______】원 — 【____】년 4대보험·소득세 기준, 공제대상가족 【_】명 기준 예상액이다. 세율·보험료율이 바뀌거나 연말정산 결과에 따라 실제 수령액은 달라질 수 있으며, 연말정산 환급금·추가 납부액은 "을"에게 귀속된다.
   - 연 환산액(참고): 【______】원 (퇴직금 별도)
2. 수습기간 임금: 【수습기간에도 위와 같은 임금을 지급한다 / 위 임금의 __%를 지급한다 (최저임금 이상)】
3. 임금 지급일: 매월 【30】일 ("을" 명의 예금 계좌로 이체). 지급일이 휴일이면 그 전날 지급한다. 임금 산정 기간은 매월 1일부터 말일까지로 한다.
4. 입사·퇴사한 달의 임금은 근무 일수에 따라 일할 계산한다.
5. 근로소득세 등 세금과 4대 보험료 근로자 부담분은 법령에 따라 공제하고 지급한다.
6. 지각·조퇴·결근·외출로 근로하지 않은 시간은 무급으로 한다.
7. "을"은 자신의 임금을 다른 임직원에게 공개하지 않으며, 다른 임직원의 임금을 알려고 하거나 공개하지 않는다.

## 6. 휴일
1. 주휴일: 일요일 (1주 소정근로일을 개근한 경우 유급)
2. 근로자의 날(5월 1일): 유급휴일

## 7. 휴가
1. 캠프나인치과는 상시 근로자 5인 미만 사업장으로 근로기준법 제60조(연차유급휴가)가 적용되지 않는다.
2. "갑"은 다음과 같이 휴가를 부여한다: 【☐ 연 ___일의 유급휴가 부여  /  ☐ 병원 휴진일(여름·겨울 휴가 등)은 ☐유급 ☐무급  /  ☐ 별도 유급휴가 없음】
3. 출산전후휴가, 육아휴직 등 법령이 정한 휴가는 법령에 따른다.

## 8. 사회보험
국민연금, 건강보험, 고용보험, 산재보험에 모두 가입한다.

## 9. 퇴직
1. 1년 이상 계속 근로하고 퇴직하는 경우 근로자퇴직급여보장법에 따라 퇴직금을 지급한다.
2. "을"이 개인 사정으로 퇴직하려는 경우 원활한 인수인계를 위해 퇴직 30일 전까지 알리도록 노력한다.

## 10. 기타
1. 이 계약서에 정하지 않은 사항은 근로기준법 등 관계 법령에 따른다.
2. "갑"은 이 계약서를 2부 작성하여 서명 날인한 후 1부를 "을"에게 교부한다.
